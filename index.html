Get Cronoff as an app

  
A real app: its own window and icon. Python, JavaScript, HTML, SQL, Lua, Ruby and C/C++ work with no internet at all, and Java, C#, Go, Rust and Kotlin run on your computer when you have them installed.

  

  
The apps are not code-signed. Windows may say "Windows protected your PC": press More info, then Run anyway. On a Mac: right-click the app, then Open. On Linux: make the file executable, then run it.
